# Hyperliquid Trader Analysis vs Bitcoin Fear & Greed Index

## Overview

This project analyzes trading behavior and performance of Hyperliquid traders in correlation with the Bitcoin Fear & Greed Index. The analysis reveals compelling patterns about when traders are most active, profitable, and risk-tolerant—specifically during periods of extreme market fear.

## Project Description

The Bitcoin Fear & Greed Index is a key indicator of market sentiment, ranging from extreme fear to extreme greed. This project explores the hypothesis that trader behavior is significantly correlated with sentiment cycles. 

**Key Finding:** Traders exhibit peak activity, profitability, and risk-taking behavior during periods of extreme market fear—a counterintuitive pattern that challenges conventional risk management wisdom.

## Objectives

- Analyze Hyperliquid trader data across multiple time periods
- Correlate trading metrics with Bitcoin Fear & Greed Index values
- Identify optimal trading windows based on market sentiment
- Quantify risk-return tradeoffs across different sentiment regimes
- Understand trader psychology during extreme market conditions

## Data Sources

- **Hyperliquid Trading Data:** On-chain trader metrics including position sizes, leverage, and PnL
- **Bitcoin Fear & Greed Index:** Historical sentiment data providing market fear/greed classifications

## Methodology

This analysis uses Jupyter Notebooks for exploratory data analysis, statistical correlation studies, and visualization of trading patterns against sentiment indicators.

## Key Insights

- Traders demonstrate increased activity during fear regimes
- Profitability metrics show interesting patterns correlated with extreme sentiment
- Risk metrics peak when fear is highest
- Temporal patterns suggest distinct trader behavior cycles

## Repository Structure

- Jupyter Notebooks containing data analysis and visualizations
- Aggregated trader metrics and sentiment data
- Statistical analysis and correlation studies

## Requirements

- Python 3.7+
- Jupyter Notebook
- pandas, numpy, matplotlib, seaborn (for data analysis and visualization)
- Additional dependencies as specified in individual notebooks

## Usage

1. Clone the repository
2. Install required dependencies
3. Open and run the Jupyter Notebooks sequentially
4. Review visualizations and statistical findings

## Results

The analysis provides actionable insights for traders interested in sentiment-based trading strategies, risk managers evaluating trader behavior, and researchers studying market psychology.
